# :hash: Tic Tac Toe

**Live Demo:** https://jlionperez.github.io/tic-tac-toe/

A fully functional Tic Tac Toe browser game built with JavaScript, HTML, and CSS. Assignment from The Odin Project Full Stack Course.

## :pencil: Features

- Two player gameplay in the browser
- Real time DOM updates reflecting game state
- Correct detection across all 8 winning combinations
- Display messages on player turns, win, and draw conditions
- Reset button clears game between rounds

## :computer: Tech Stack

- JavaScript (ES6)
- HTML5
- CSS3

## :memo: Concepts Applied

- IIFE module pattern to encapsulate game state and logic
- Factory function to create Player objects
- 1D array game board with event driven DOM manipulation
- Iterative debugging of turn switching and win condition logic

## :gear: How to Run Locally

1. Clone the repository:   
```https://github.com/JLionPerez/tic-tac-toe.git```

2. Navigate into the project folder:   
```cd tic-tac-toe```

3. Open the ```index.html``` file in your browser.
